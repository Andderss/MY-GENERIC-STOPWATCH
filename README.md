# ⏱️ Mi feo Stopwatch en Python

> *"Todo programador senior empezó sufriendo con un `while` y le costó entenderlo (pongámosle). Este es mi comienzo."*

¡Bienvenido a mi cronómetro! Un proyecto 100% honesto, funcional y con mucha personalidad (lo juro). Sí, sé lo que estás pensando: "¿Otro cronómetro en Python? bruh". Absolutamente. No va a hackear la NASA ni tiene una IA incluída o algo así, pero al menos cuenta los milisegundos de forma impecable sin que algo explote lul.

⚠️ **Aviso importante:** Este es un proyecto estrictamente de práctica. Sé que es algo sumamente sencillo, pero por algún lado hay que empezar para ir mejorando de a poco, soltar los dedos con la lógica y entender cómo funcionan las interfaces gráficas. Ideal para ir midiendo mis tiempos o ver si logro pausarlo justo en un '.00'. 

## 🛠️ Tecnologías y Librerías

Este cronometro fue hecho con las siguientes herramientas:

*   **`tkinter`**: Para la interfaz gráfica. Porque no quería que fuera en la terminal jiji.
*   **`datetime`**: (Junto con `timedelta`) Para ser el cerebro detrás de los cálculos matemáticos temporales. (me imagino que habían formas más sencillas)

## 🚀 Cómo usarlo

Si por alguna extraña razón quieres tener esta magnifica obra de ingeniería en tu computadora, los pasos son los siguientes:

1. Asegúrate de tener Python instalado.
2. Clona este repositorio o descarga el archivo.
3. Abre el archivo en el editor de codigo que quieras y clickea "Run Python File" (Ese que tiene botón de Play)
4. Esperemos que funcione bien. :p
